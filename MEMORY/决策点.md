# 已确认决策

## 2026-09-09：个人内容网站首版方向

- 定位：持续更新的内容站，不以个人简历展示为核心。
- 内容：AI 应用技术分享（个人学习与总结、案例分享）与交易系统分享（理念与规则、风控与仓位管理、系统复盘）。
- 视觉：编辑型内容站，首页以精选长文与最新内容流为核心。
- 发布：本地 Markdown 写作，经 Git 提交自动构建并部署到云服务器。
- 技术：Astro 静态站、Nginx 托管；无数据库、无在线后台。
- 工程结构：使用 `frontend/` 与 `backend/` 分离；`backend/` 仅包含部署和运维文件，不实现 API、数据库或业务后端。
- 范围：不做登录、评论、点赞、搜索、付费和实时行情。
